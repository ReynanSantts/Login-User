# TecLog

## Sobre o sistema
O TecLog é um sistema web desenvolvido para realizar o cadastro, login e gerenciamento de acesso dos usuários.

## Funcionalidades
- Cadastro de usuários.
- Login e logout.
- Recuperação de senha por e-mail.
- Redefinição de senha.
- Página inicial com informações do usuário.

## Tecnologias utilizadas
- HTML, CSS e JavaScript.
- Node.js e Express.
- SQL Server.

## Requisitos de qualidade
- **Segurança:** criptografia de senhas e proteção de acesso.
- **Usabilidade:** interface simples e intuitiva.
- **Confiabilidade:** validação dos dados e tratamento de erros.
- **Organização:** separação do código em rotas, controllers e models.

## Como funciona
O usuário realiza seu cadastro e acessa o sistema utilizando e-mail e senha. Após a autenticação, é direcionado para a página inicial, onde pode visualizar suas informações. Caso esqueça a senha, pode solicitar sua recuperação por e-mail.
